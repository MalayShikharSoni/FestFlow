## How to read this

- **COLLSCAN** reads every document in the collection; **IXSCAN** walks only the matching index keys.
- `docsExamined` far above `nReturned` means wasted work; with a good index they are close.
- A `SORT` stage means the results were sorted in memory; with `{type: 1, startTime: 1}` the index order already is the sort order, so the stage disappears (equality field first, sort field second).
- `PROJECTION_COVERED` with `docsExamined: 0` is a covered query.
- `EXPRESS_IXSCAN` (MongoDB 8.0+) is a fast path for an equality match on a unique index: it skips the general query planner.
